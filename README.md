# TP 08 — Gestion des utilisateurs avec Vue.js et une API REST

Frontend : Vue 3 (Composition API, Vite, Vue Router) — API simulée avec json-server

## Installation

    npm install

## Lancement (2 terminaux)

    npm run api     # API REST sur http://localhost:3000/utilisateurs
    npm run dev     # application Vue (adresse affichée par Vite)

## Contenu

- Partie 1 : liste, ajout, modification, suppression avec confirmation (Fetch : GET, POST, PUT, DELETE)
- Partie 2 : recherche par nom ou prénom
- Partie 3 : état actif/inactif (badge + bouton, PATCH dans l'API)
- Partie 4 : filtre tous / actifs / inactifs
